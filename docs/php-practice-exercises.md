# Практические уроки по PHP

Курс на сайте: https://fkn.ktu10.com/?q=node/17702

Тексты уроков готовятся локально в соседнем репозитории: `../php-practice-exercises`
(возможный путь относительно корня `ktu10-helper`, если папки лежат рядом) — а затем публикуются на сайте.

В репозитории лежит docker-окружение для уроков (`lessons-v1/`: nginx + php-fpm + xdebug,
Makefile для запуска) и примеры уроков в `lessons-v1/lessons/`.
