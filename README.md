## Разметка текста

В данный момент сайт не поддерживает markdown разметку, поэтому работаем с HTML

Пример форматирования текста с кодом:

```html
Предположим, требуется проверить, что значение температуры лежит в пределах от 25 до 30 градусов. Этого можно достичь, например, при помощи вложенных операторов <code>if</code>:

<pre class="brush: php">
$temperature = 27;
if ($temperature >= 25) {
  if ($temperature <= 30) {
    echo ("Комфортная температура" ) ;
  {
}
</pre>

```

### Абзацы 

Абзацы можно не брать в тэг <p> он автоматически добавится системой отображения сайта - в тексте просто пересим строки

## Перекрестные ссылки между уроками - когда и как ссылаться

Очень хорошо делать перекресный ссылки (можно с относительными URL) - особенно на предыдущие уроки того же курса.

При этом: ссылаться назад полезно и правилно, а вот ссылаться вперед _не сильно желательно_, лучше писать "это разберем далее" или "в следующих уроках" и ссылаться на список уроков.

Как мы определяем порядок: по положению урока в списке уроков на корневой странице курса (а не по дате создания/id страницы).

### Текст ссылок на уроке

Текст ссылок в тексте сслок на уроке лучше указывать не номер урока (который в теории может поменяться) а более органично писать смысл, например вместо "урок 2" писать "урок про переменные" или даже просто само слово  "переменные" делать ссылкой т.е. органично вписывать ссылку в текст и при этом делать это минимально по объему видимой вставки. 

Превращать в ссылку можно слово или словосочетания (или даже несколько слов), если это подходит по смыслу, то есть 2-3 слова даже предпочтительнее одного (опять же, если это подходит по смыслу)
